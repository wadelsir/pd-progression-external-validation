# Synthetic demonstration data

`synthetic_example_dataset.csv` contains fully simulated records generated with a fixed random seed. It contains no PPMI, PDBP, AMP-PD, or other real participant information.

The file reproduces the expected predictor names, data types, missing-value patterns, cohort labels, and binary outcome structure so that the public pipeline can be tested end to end. Synthetic results must not be interpreted as scientific findings and will not reproduce the numerical results reported in the manuscript.
