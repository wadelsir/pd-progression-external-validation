# Supplementary Methods S1. Instructions for reconstruction of the analytical datasets

Researchers seeking to reproduce the analysis must first obtain independent authorization to access the PPMI and AMP-PD/PDBP data resources and comply with the corresponding data-use agreements. After access is granted, the required source tables should be documented using the manifest templates and placed in a secure directory outside the public repository.

The notebooks reconstruct the eligible Parkinson's disease cohorts, derive the annualized MDS-UPDRS Part III outcome, create the seven harmonized clinical predictors, fit or load the locked preprocessing and prediction pipelines, and reproduce aggregate internal and external performance summaries. Public synthetic data reproduce the expected column structure and data types but contain no real participant records and cannot reproduce the numerical findings reported in the manuscript.
